# easySales server

Express 5 + TypeScript API, LangChain/LangGraph agents and the job worker. See the [root README](../README.md).

- `npm run dev`: API with in-process worker (tsx watch)
- `npm run worker`: standalone worker
- `npm test`: node:test suite (in-memory MongoDB, fake LLM)
- `npm run typecheck`, `npm run build`, `npm run seed:demo`
